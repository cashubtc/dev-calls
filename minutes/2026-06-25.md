### NUTs

#### Edits
* [NUT-12](https://github.com/cashubtc/nuts/pull/368) - deterministic DLEQ nonce derivation
  * HMAC-SHA256 nonce derivation with rejection sampling and new test vectors
* [NUT-11](https://github.com/cashubtc/nuts/pull/358) - tighten NUT-11 spending conditions
  * clarifies rejection of malformed P2PK secrets
* [NUT-00/17](https://github.com/cashubtc/nuts/pull/383) - recommend UUID v7 for quote and websocket subscription IDs
  * updates NUT-04/05 quote IDs, NUT-17 `subId`, and examples
* [NUT-24](https://github.com/cashubtc/nuts/pull/393) - explicitly allow `creqB` payment requests in 402 payments

#### New
* [Proof of Liabilities](https://github.com/cashubtc/nuts/pull/388) - draft PoL spec using Sparse Merkle Sum Trees and signed receipts
* [V3 binary secret encoding](https://github.com/cashubtc/nuts/pull/389) - draft binary `Proof.secret` envelope and NUT-10 condition payload encoding
* [Non-Interactive Mint Delegation on Liveness Failure / Nimdolf](https://github.com/cashubtc/nuts/pull/390) - draft failover redemption proposal for delegated mints
* [NUT-XX: replay-protect pubkey quote lookup signatures](https://github.com/cashubtc/nuts/pull/391) - amendment intended for [Get quotes by pubkeys](https://github.com/cashubtc/nuts/pull/341)

#### Needs love
* [NUT-00: BLS12-381 v3 protocol](https://github.com/cashubtc/nuts/pull/371) - very active review; adds v3 pairing-based BDHKE, key serialization, keyset ID, deterministic recovery, and test vectors
* [Payment request consolidation](https://github.com/cashubtc/nuts/pull/381) - consolidates preferred/strict mints, supported methods, and fee reserve; current discussion around flipping `mint_strict` semantics to `mint_preferred`
* [Custom payment methods](https://github.com/cashubtc/nuts/pull/382) - base quote structs for custom/unknown methods; tied to quote `method` field work
* [Add `method` field to quote responses](https://github.com/cashubtc/nuts/pull/387) - implemented in cashu-ts and nutshell, CDK still TBD
* [NUT-04 quote accounting](https://github.com/cashubtc/nuts/pull/377) - aligns mint quote accounting on `amount_paid`, `amount_issued`, and `updated_at`
* [NUT-29 signature message separator](https://github.com/cashubtc/nuts/pull/375) - fixes batch minting / NUT-20 message-to-sign construction; CDK support still open
* [NUT-17 subscription kinds](https://github.com/cashubtc/nuts/pull/372) - simplifies websocket quote subscriptions to generic `mint_quote` / `melt_quote`
* [NUT-20 deterministic quote locking derivation](https://github.com/cashubtc/nuts/pull/373) and [deterministic P2PK generation](https://github.com/cashubtc/nuts/pull/331) - active around BIP32 vs KDF tradeoffs
* [Offline Spilman channel](https://github.com/cashubtc/nuts/pull/296) - fresh MONAD / payment-channel implementation update on Jun 25
