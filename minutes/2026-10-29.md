### NUTs

#### Edits
* [NUT-25](https://github.com/cashubtc/nuts/pull/448) - define the mint quote response amount
  * bolt12 mint quote response `amount` echoes the requested amount, or is `null` for an amountless offer
* [NUT-28](https://github.com/cashubtc/nuts/pull/402) - add HTLC example proof to test vectors
  * pinned in Cashu-TS, CDK (wallet side) and Nutshell
* [Editorial pass](https://github.com/cashubtc/nuts/pull/454) - broken anchors, invalid JSON, and names no NUT defines

#### New
* [NUT-XX: Signing packages](https://github.com/cashubtc/nuts/pull/464) - `nutspA` package for passing a nutroot script-path spend between co-signing wallets; follow-on to [#443](https://github.com/cashubtc/nuts/pull/443)
* [NUT-XX, NUT-YY: fixed txout quotes and the template leaf](https://github.com/cashubtc/nuts/pull/457) - draft, stacked on [#445](https://github.com/cashubtc/nuts/pull/445)
* [NUT-XX: Mint quote lookup by public key with pagination](https://github.com/cashubtc/nuts/pull/459) - supersedes [Get quotes by pubkeys](https://github.com/cashubtc/nuts/pull/341); adds signed timestamps, pagination and operator-enforced limits

#### Needs love
* [NUT-00: BLS12-381 v3 protocol](https://github.com/cashubtc/nuts/pull/371) - stack #371 / #443 / #445 / #457; see the Reviewers Guide to Nutroot linked in the PR
* [NUT-10: Nutroot secrets (v3 keysets)](https://github.com/cashubtc/nuts/pull/443) - secret is a secp256k1 pubkey with spending conditions committed taproot-style
* [Spec reorg: current NUTs only, everything pre-v3 in legacy/](https://github.com/cashubtc/nuts/pull/430) - draft, looking for a read on the approach
* [NUT-02, NUT-08: settle pending melts before rotating a keyset out](https://github.com/cashubtc/nuts/pull/436) - zero-value signatures MUST be omitted
* [NUT-02: keyset active window](https://github.com/cashubtc/nuts/pull/438) - `active_from` / `active_until` for locked outputs
* [NUT-11: typed, length-framed SIG_ALL message](https://github.com/cashubtc/nuts/pull/404) - implemented in Cashu-TS (v4, v5), Nutshell and CDK
* [NUT-06: require signed mint info](https://github.com/cashubtc/nuts/pull/416) and [mint response signatures](https://github.com/cashubtc/nuts/pull/437)
* [Loosen NUT-29 batch quote checks](https://github.com/cashubtc/nuts/pull/422) - Cashu-TS done; Nutshell open, CDK TBC

### Libraries and Mints
* CDK
  * [cdk v0.18.2](https://github.com/cashubtc/cdk/releases/tag/v0.18.2)
      * Seed-based recovery of NUT-20 signing keys for known mint quotes (`fetch_mint_quote_with_key_search`, `cdk-cli mint --quote-id`)
      * Fixes persisted wallet quote state, and LND payment validation and rounding
      * Fixes legacy mint configuration imports

* CDK Bindings
  * [cdk-go v0.18.2](https://github.com/cashubtc/cdk-go/releases/tag/v0.18.2), [cdk-dart v0.18.2](https://github.com/cashubtc/cdk-dart/releases/tag/v0.18.2), [cdk-kotlin v0.18.2](https://github.com/cashubtc/cdk-kotlin/releases/tag/v0.18.2), [cdk-swift v0.18.2](https://github.com/cashubtc/cdk-swift/releases/tag/v0.18.2)

* cashu-ts
  * [cashu-ts v4.13.0](https://github.com/cashubtc/cashu-ts/releases/tag/v4.13.0) - end-to-end NUT-18 payment request handling in v4
      * `sendToRequest`: pay a request in one call with fees, mints and locks handled
      * `isPaymentRequestSatisfied`: payees check incoming ecash in one call
      * `mp` / `sm` support, at parity with v5
  * [cashu-ts v4.12.0](https://github.com/cashubtc/cashu-ts/releases/tag/v4.12.0)
      * feat(utils): add `verifyMintSignatures` ahead of v5, deprecate `hasValidDleq`
      * fix(core): validate text fields when decoding a v4 token
      * fix(nut11): read locktime 0 as an expired lock, expire only after locktime
  * [cashu-ts v5.0.0-rc.12](https://github.com/cashubtc/cashu-ts/releases/tag/v5.0.0-rc.12)
      * Implements the simplified Nutroot core
      * Proof verification, state checks and restore now run in chunks that yield to the event loop, and mint errors can be matched by code (MintErrorCode plus predicates)
      * Breaking changes for rc.11 upgraders - read the migration guide!

* Pecan
  * [Pecan v0.4.0](https://github.com/zeugmaster/pecan/releases/tag/v0.4.0)
      * Keys tab: a console view of the mint's keysets and their expiry
      * Activity tab: searchable activity history
      * Mint tab now shows its status first

#### New Wallets
* [tmp.cash](https://tmp.cash) - a non-custodial ecash wallet that transfers ecash without revealing changes of ownership to the mint. The mint issues ecash, but cannot collect or spend that deposit until final redemption
* [NutBar](https://github.com/Amperstrand/nutbar) - a Cashu wallet for the Omarchy status bar with TollGate captive Wi-Fi auto-pay
* [Cashu Browser](https://github.com/zeugmaster/cashu-browser) - a Cashu wallet extension for Chrome and Safari, built with Coco, that can also pay HTTP 402 requests
* [find-my-nuts](https://github.com/zeugmaster/find-my-nuts) - a proof-of-concept ESP32 Cashu wallet that broadcasts ecash tokens over Apple's Find My network
* [Cashu for M5Stack PaperS3](https://github.com/Emzy/papers3-cashu) - an experimental port of the Nucula wallet to the M5Stack PaperS3 e-paper device

#### Wallets Updates
* [Cashu Wallet v1.0.0](https://github.com/cashubtc/wallet/releases/tag/v1.0.0)

* [macadamia v0.11.0](https://github.com/zeugmaster/macadamia/releases/tag/v0.11.0)

* Minibits

    * [Minibits v0.4.4-beta](https://github.com/minibits-cash/minibits_wallet/releases/tag/v0.4.4-beta.1)
        * Bundles all over-the-air updates published over the past 5 months
        * Fixes processing of zaps over Nostr Wallet Connect on Android
        * Ecash minting and melting via Bitcoin onchain transactions

* [Zeus v13.2.3](https://github.com/ZeusLN/zeus/releases/tag/v13.2.3)
    * Bump Cashu Dev Kit to 0.17.3: fix ecash operations against cdk-mintd 0.17 mints (Minibits)
    * Harden Cashu proof db at rest and on delete
    * Omit zero-valued NUT-11 tags so P2PK tokens are redeemable

### Various Projects
* [Nonfungible.cash](https://github.com/callebtc/cashu-nft) - private bearer NFTs and a marketplace on Cashu ecash, where the ownership token travels inside the image file
* [Cashu Card JavaCard applet](https://github.com/lnflash/cashu-javacard/tree/main) - an experimental JavaCard applet for offline NFC ecash payments with a physical card
* [dvm-cli](https://github.com/dvmkit/dvm-cli) - a command-line client and agent skill for pay-per-use services that AI agents can pay for without accounts or API keys
* [Sats4Tokens](https://github.com/beihaili/sats4tokens) - pay sats over Lightning or Cashu and get a capped AI API key, with no signup
* [SOLVENT](https://github.com/TheWeirdDee/solvent) - checks a Cashu mint's signed Proof-of-Liabilities receipt against its accounting, Nostr state and a Bitcoin Signet reserve
* [nutgraph](https://ye0man.github.io/nutgraph/) - a knowledge graph of the Cashu ecosystem, with the spec at the center and modules and their dependents around it
* [CypherGuide](https://github.com/greenweaveglobal/CypherGuide) - a peer-to-peer lodging protocol with Nostr identity and Lightning/Cashu payments
* [Nutflix demo](https://github.com/SovereignTechnology/nutflix-demo) - a peer-to-peer paid video network demo using Nostr and Cashu ecash
* [omarchy-routstr](https://github.com/babdbtc/omarchy-routstr) - an Omarchy plugin for buying Routstr AI inference privately, paid per request with Lightning or Cashu
* [Tessera](https://github.com/gwbtc/tessera) - blind-signed access tokens for Urbit using Cashu NUT-22 auth mints
* [L3](https://github.com/JacksonZheng07/L3) - trust scoring for Cashu mints that automatically moves funds over Lightning when a mint degrades
* [Real Open Bidding](https://github.com/ye0man/real-open-bidding) - a prototype of prepaid, decentralised ad auctions over Nostr with Cashu NUT-11 ecash
* [Numo POS spike](https://github.com/Amperstrand/numo-pos-spike) - a hackathon demo of a restaurant checkout that takes payment with the Numo Cashu POS
* [nutpub](https://github.com/rajesh-taylor/nutpub) - a show paid for in Cashu ecash, 10 seconds at a time, over HTTP 402 (NUT-24)
* [Cashu Unlinked](https://github.com/brainx/cashu-unlinked) - a playable privacy investigation game that explores Cashu blind signatures
